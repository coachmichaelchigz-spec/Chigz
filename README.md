# Coach Michael

A personal-trainer fitness app built with React + Vite. It's a mobile-first,
single-screen app with four tabs:

- **Home** – greeting, weekly stats, today's plan, week overview, and muscle groups
- **Explore** – browse all muscle groups
- **Workout** – per-exercise detail with a tap-to-complete set tracker
- **Profile** – lifetime stats

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

Then open the URL Vite prints (default http://localhost:5173).

## Project structure

```
index.html            # app entry HTML
src/main.jsx          # React root
src/CoachMichael.jsx  # the full app component
vite.config.js        # Vite + React plugin config
```
