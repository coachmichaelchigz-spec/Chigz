# Monate Guest House

A complete, high-converting single-page marketing website for **Monate Guest
House** — a peaceful, affordable guest house at 30 Hospital Street, Medipark,
Tzaneen, Limpopo, 0850.

Everything lives in one standalone `index.html` file: pure HTML, CSS and
JavaScript with no build step and no dependencies (only Google Fonts via CDN).

## Sections

- **Hero** – full-screen with overlay, headline and "Book Your Room Now" CTA
- **About** – warm intro to the guest house
- **Rooms & Amenities** – en-suite, TV, secure parking, bar, garden, WiFi
- **Location** – embedded Google Map + nearby restaurants & attractions
- **Reviews** – Google reviews with star ratings and 3.9★ rating badge
- **Booking CTA** – WhatsApp + phone call buttons
- **Footer** – address, phone, Google Maps link, copyright
- Floating WhatsApp button, sticky header, smooth scroll, fade-in animations

## Run it

No build required — just open the file in any browser:

```bash
open index.html      # macOS
# or simply double-click index.html
```

## Customising

Replace the placeholder contact details before going live:

- **Phone number** – search for `27000000000` and `+27 00 000 0000`
- **WhatsApp** – the `https://wa.me/27000000000` links use the same number
- **Colours** – tweak the CSS variables in the `:root` block at the top of the
  `<style>` section
